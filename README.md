# Átila Luna

**PhD candidate at PUC-Rio** · Scientific Machine Learning for reservoir simulation

I develop machine learning surrogates for subsurface flow, with a focus on **neural operators** (FNO), *solver-in-the-loop* training and **physics-informed neural networks**. Outside research, I build software end to end, from LLM-based assistants to mobile and web apps.

### Research interests
- Neural operators and hybrid ML–numerical solvers for reservoir simulation
- Physics-informed neural networks for multiphase flow (Buckley–Leverett, fractional flow)
- Numerical methods, well testing and Laplace-domain inversion
- Retrieval-augmented generation (RAG) for engineering knowledge

### Publications
- **Applications of Physics-Informed Neural Networks to the Buckley–Leverett Equation.** *SPE Latin American and Caribbean Petroleum Engineering Conference (LACPEC)*, 2026. [doi:10.2118/231709-MS](https://doi.org/10.2118/231709-ms)
- **Physics-Informed Neural Network Applied to Fractional Flow Equations.** M.Sc. dissertation, PUC-Rio, 2023. [doi:10.17771/PUCRio.acad.65007](https://doi.org/10.17771/pucrio.acad.65007)
